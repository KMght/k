# 最高裁判所規則集

裁判所が公開している最高裁判所規則のPDFを、条ごとにリンクを張れるHTMLに変換したものです。104件を収録しています。

条文の正確な内容は、各ページの「原本 p.○」から裁判所のPDFで確認してください。

## 構成

```
index.html          総目次（分野別・規則名でしぼり込み可）
r/100.html          規則の本文（3桁IDがファイル名）
r/100.json          同じ規則の構造データ
r/100.links.tsv     本文中に張ったリンクの一覧
r/100.laws.tsv      他法令へのリンクの一覧
db/rules.json       規則マスタ104件
db/aliases.json     略称辞書
db/articles/100.json  条・アンカーの一覧
db/ksk_schema.sql   SQLite スキーマ
```

## 規則ID

3桁の数字で、先頭桁が分野を表します。IDは変わりません。規則が改正されても、施行日が変わっても、同じ番号のままです。

| 先頭桁 | 分野 | 使用済み |
|---|---|---|
| 1 | 民事訴訟 | 100–112 |
| 2 | 民事執行・保全 | 200–211 |
| 3 | 倒産・再生・責任制限 | 300–306 |
| 4 | 家事・人訴・調停・少年・医療観察 | 400–411 |
| 5 | 非訟・仲裁・人身保護 | 500–509 |
| 6 | 刑事 | 600–623 |
| 7 | 裁判所組織・司法行政 | 700–719 |
| 8 | IT・電子化 | 800–803 |
| 9 | 経過措置・地域特例 | 900–901 |

各ブロックの51番以降は将来枠です。廃止された規則の番号は再利用しません。

主要な規則は各分野の先頭に置いています。100 民事訴訟規則、200 民事執行規則、300 破産規則、400 家事事件手続規則、500 非訟事件手続規則、600 刑事訴訟規則。

## URLの作り方

```
https://kmght.github.io/ksk/r/{ID}.html#{アンカー}
```

| 対象 | アンカー | 例 |
|---|---|---|
| 条 | `a9` | `r/100.html#a9` （民訴規9条） |
| 条の枝番 | `a105-2` | `r/100.html#a105-2` （105条の2） |
| 項 | `a9-p2` | `r/100.html#a9-p2` （9条2項） |
| 号 | `a9-p2-3` | `r/100.html#a9-p2-3` |
| 編・章・節 | `d12` | `r/100.html#d12` |
| 附則の条 | `sup1-a1` | `r/100.html#sup1-a1` |
| e-Gov互換 | `Mp-At_105_2` | `r/100.html#Mp-At_105_2` |

`a` 系を正とし、`Mp-At_` 系はe-Govからのコピペ用に併記しています。

## db の使い方

規則名から条項のURLを組み立てるためのデータです。

1. `aliases.json` で規則名を最長一致で引き、`rule_id` を得る。`priority` が小さいものを優先する。
2. `articles/{rule_id}.json` で条の実在と項番号を確認する。`anchor` がそのままURLの断片になる。
3. `caption`（条見出し）はツールチップに使える。

`ksk_schema.sql` は、この3ファイルからSQLiteの索引を作る場合のスキーマです。

## 収録データについて

- 各規則は現行版（最新施行版）のみを収録しています。過去版は置いていません。
- `enforcement_iso` が空の19件は、原本PDFから施行日を確定できていないものです。本文は最新PDF由来です。
- 別表・様式は条ではないため `articles` に含みません。本文HTMLには `table-` で始まるアンカーで残しています。
